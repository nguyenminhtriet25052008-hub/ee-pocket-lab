# Contributing

Contributions from fellow Electrical, Electronics & Embedded Engineering students and engineers are welcome!

1. **Zero external dependencies**: Python 3.8+ standard library only.
2. **Concise & readable**: Keep each calculator around 50–85 lines in `tools/`.
3. **Engineering accuracy**: Use standard formulas (IPC-2221, E12/E24 series, IEEE/ITU CRC polynomials) and add unit tests in `tests/test_tools.py`.
4. **Run tests locally**:
   ```bash
   python -m unittest discover -s tests -v
   ```
